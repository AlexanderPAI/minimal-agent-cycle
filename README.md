# minimal-agent-cycle
Самостоятельное изучение. Мини-агент с управляемым циклом. Неделя 2

# Цель задания

Самостоятельно реализовать на Python минимального агента без агентных фреймворков. 
Агент должен решать простую многошаговую задачу, использовать два локальных фиктивных инструмента, 
хранить историю шагов и гарантированно завершаться.

# Сценарий

Создать агента для ответа на вопросы о заказах из небольшой локальной тестовой базы.

Примеры запросов:
```text
Какова итоговая стоимость заказа ORD-101 с доставкой?
```

```text
Проверь заказ ORD-999 и сообщи его итоговую стоимость.
```

```text
Посчитай итоговую стоимость моего заказа.
```

Чтобы выполнить задачу, агенту могут понадобиться два действия:
1. `lookup_order` - найти заказ по идентификатору
2. `calculate_total` - рассчитать сумму товаров и доставки

Это локальные функции.

**Условности:**
- не подключать реальную БД (при желании можно использовать SQLite)
- не подключать нативный `tool_calling` из `OpenRouter`

# Обязательные требования по стеку
- Python 3.11 или новее
- openrouter
- Pydantic для состояний и решений
- Один явно выбранный идентификатор модели
- Не использоваться LangChain, LangGraph, PydanticAI или агентные SDK
- Не использовать `eval`, `exec`, команды оболочки и динамический импорт
- Не сохранять скрытые рассуждения модели
- Максимум 5 логических шагов по умолчанию
- Автоматические тесты не должны обращаться к OpenRouter
