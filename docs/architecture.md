Статусы:
```text
running
   ├── success
   ├── failed
   └── needs_input
```

```text

│ Пользователь передаёт цель  │

        │ да          │ нет

Терминальное состояние:
success / failed / needs_input
               ↓
┌─────────────────────────────┐
│ Формирование ответа         │
│ пользователю                │
└─────────────────────────────┘
```

Состояние агента содержит:

- цель пользователя;
- текущий статус;
- количество выполненных шагов;
- максимальное количество шагов;
- найденные данные о заказе;
- рассчитанную сумму;
- историю действий;
- финальный ответ;
- ошибку.

Модель может предложить:

- найти заказ;
- рассчитать сумму;
- завершить задачу;
- запросить недостающие данные.

Переходы между статусами:

running → success
Когда заказ найден и сумма рассчитана.

running → failed
Когда исчерпан max_steps или возникла непоправимая ошибка.

running → needs_input
Когда пользователь не указал идентификатор заказа.

running → running
Когда действие выполнено, но для достижения цели нужен ещё один шаг.
